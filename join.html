Private chat over Tor

You've been invited to kairos-server

A chat server with channels, running on a machine Kairo owns rather than a company's. Setting it up takes about five minutes, most of it waiting for a download.

Your join code

8 digits

Everyone joining uses this same code. It's the whole invitation — there's no address, username or password to go with it.

01

Install it

tor2 runs in a terminal, on Linux or macOS. Paste these in one at a time.

First, the things it needs

$ sudo apt install -y tor git python3-venv ffmpeg

On macOS use brew install tor git python ffmpeg instead.

Then tor2 itself

$ git clone https://github.com/KairoWolf/tor2.git $ cd tor2 $ python3 -m venv .venv $ .venv/bin/pip install -r requirements.txt

Start it with:

$ .venv/bin/python -m tor2
02

Wait for Tor to connect

The first launch takes 30 to 60 seconds while it finds its way onto the Tor network. It says bootstrapping while it works. This only feels slow the first time.

You don't need to install Tor Browser or set anything up — tor2 starts its own Tor and shuts it down when you quit.

03

Enter your code

Type this into the message box at the bottom, digits and all:

/join 12345678

That's it — you'll land in #general. Set a name for yourself with /nick yourname, and /help lists everything else.

If the code doesn't work

A code only works while the server is switched on — it can't be looked up anywhere in advance. If it's refused, the server is probably down rather than the code being wrong. Give it a minute, then tell Kairo.

04

What this does and doesn't hide

Worth knowing before you say anything you'd rather keep private.

  • Kairo can read this server. Messages in channels are decrypted on the server to be delivered and stored — the same as any self-hosted chat. Whoever runs it can read it.
  • One-to-one chats are different. Those go straight between the two devices with no server in the middle, and nobody else can read them — not even Kairo.
  • Your IP address is hidden from the server and from other members, because everything travels over Tor.
  • Nothing to sign up for. No email, no phone number, no account.

The project writes this up honestly, including the weak spots, in its security notes.
